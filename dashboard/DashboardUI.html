1. Kết nối bot Zalo

Kiểm tra Bot Token đã cài trong thuộc tính tập lệnh.

Chưa kiểm tra.

2. Lấy Chat ID

Nhấn Tìm Chat ID mới trước, sau đó ngay lập tức mở Zalo gửi MALOI đến bot trong lúc nút đang xử lý (khoảng 20 giây).

Chưa tìm Chat ID. Nếu sau 20 giây vẫn không nhận được tin, cần kiểm tra webhook hoặc địa chỉ API đang sử dụng.

3. Gửi tin nhắn thử

Chỉ thử sau khi kiểm tra token và lưu Chat ID.

Chưa gửi thử.

4. Kiểm tra nguồn công việc

Xem thử dữ liệu Sheets. Không chỉnh sửa hoặc xóa công việc.

Chưa đọc dữ liệu.

Hướng dẫn sử dụng

  1. Cài ZALO_BOT_TOKEN và ZR_ADMIN_EMAIL trong Script Properties.
  2. Triển khai Dashboard GAS dưới dạng Web App, Execute as: Me, Who has access: Only myself.
  3. Mở Dashboard bằng đúng tài khoản Google đã đăng ký, kiểm tra Bot Token.
  4. Gửi tin mới cho bot và bấm Tìm Chat ID mới, sau đó lưu.
  5. Gửi tin nhắn thử, kiểm tra dữ liệu công việc rồi mới cài lịch chạy zrInstallTrigger.

Ghi chú: Dashboard này sử dụng long polling theo thao tác bấm nút, không tự tạo hoặc xóa webhook.
